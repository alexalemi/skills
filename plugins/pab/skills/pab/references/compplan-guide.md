# Kissimmee 2040 Comprehensive Plan: PAB Guide

This guide provides detailed information about the Kissimmee 2040 Comprehensive Plan structure, content, and how to effectively use it for Planning Advisory Board (PAB) analysis.

## Overview

**Location:** `./references/compplan/`
**Total Documents:** 11 txt files (extracted from original 646-page comprehensive plan PDFs)
**Plan Horizon:** 2040
**Base Adoption:** November 2018
**Recent Amendments:** February 2020, December 2021, December 2022

The Kissimmee Comprehensive Plan follows the structure mandated by **Florida Statutes Chapter 163**, which requires local governments to adopt comprehensive plans with specific elements addressing land use, transportation, housing, infrastructure, and other community development topics.

## Document Structure

### Individual Element Text Files (01-11)

Each element text file contains the extracted text from the original PDFs including:
1. **Goals, Objectives, and Policies (GOP)** - The regulatory/enforceable component
2. **Maps** - Descriptions and references (original visual maps are in source PDFs if needed)
3. **Data, Inventory, and Analysis (DIA)** - Supporting documentation and context

### Consolidated GOPS Document

**Comp Plan_12.2022_GOPS Only_reduced.txt** contains ONLY the Goals, Objectives, and Policies from all elements without the supporting maps, data, or analysis. This is your primary working reference.

### Policy Numbering System

- **Goals:** Numbered by chapter (Goal 1.1, Goal 2.1, Goal 3.1, etc.)
- **Objectives:** Hierarchical under goals (Objective 1.1.1, Objective 2.1.3, etc.)
- **Policies:** Numbered under objectives (Policy 1.1.1.1, Policy 2.1.3.2, etc.)

**Example:**
- Goal 1.1: Land Use and Community Character
  - Objective 1.1.1: Residential Quality
    - Policy 1.1.1.1: Specific residential requirement
    - Policy 1.1.1.2: Another residential requirement

## Recommended PAB Workflow

### Step 1: Initial Application Review

**Primary Document:** Consolidated GOPS (Comp Plan_12.2022_GOPS Only_reduced.txt)

1. Read the application/staff report
2. Identify the application type (rezoning, site plan, CPA, variance, etc.)
3. Note key characteristics (land use, density, location, special features)
4. Open the consolidated GOPS text file

### Step 2: Search for Applicable Policies

**Search Strategy:**

Use text search (grep, Ctrl+F in editor, or Read tool) for these terms:
- Specific land use category mentioned in application
- "Compatible" or "compatibility"
- "Consistent" or "consistency"
- "Shall" (mandatory requirements)
- Key features (e.g., "affordable housing," "mixed-use," "historic")
- Location-specific terms (e.g., "MMTD," "CRA," "Historic Preservation Overlay")

### Step 3: Element-Specific Analysis

Focus on these elements based on application type:

**For Comprehensive Plan Amendments / Rezoning:**
- ✅ FLUE: Goals 1.1 and 1.2 (especially applicable land use objectives)
- ✅ TE: Goal 2.2 (land use/transportation linkage)
- ✅ CIE: Goal 8.1 (concurrency)

**For Residential Developments:**
- ✅ FLUE: Objectives 1.1.1, 1.2.1
- ✅ HE: All of Goal 3.1
- ✅ TE: Objective 2.2.2 (housing/transportation linkage)
- ✅ PFE: All sub-elements for infrastructure
- ✅ CIE: LOS standards
- ⚠️ CONS: If environmental features present
- ⚠️ ROSE: Check parkland dedication

**For Commercial / Mixed-Use Developments:**
- ✅ FLUE: Objectives 1.1.2, 1.2.2, 1.2.3, 1.2.5
- ✅ TE: Goals 2.1 and 2.2, access management plans
- ✅ PFE: Infrastructure capacity
- ✅ CIE: Concurrency
- ⚠️ EDEV: If economic development incentives involved

**For MMTD Projects:**
- ✅ FLUE: Objective 1.2.11 (MMTD-specific policies)
- ✅ TE: Entire element, especially Goals 2.1 and 2.2
- ✅ CIE: Infrastructure requirements

**For Projects with Environmental Features:**
- ✅ CONS: All of Goal 5.1
- ✅ FLUE: Objective 1.1.5 (resource conservation)
- ✅ PFE: Chapters 4C (aquifer recharge) and 4D (stormwater)

**For Historic Properties:**
- ✅ FLUE: Objectives 1.1.7, 1.2.10
- ✅ HE: Objective 3.1.5
- 📋 Check HE Appendix A for historic properties list

### Step 4: Deep Dive (When Needed)

When you need more context or supporting data:

1. Open the specific element text file (e.g., 01_FLUE_Dec21.txt)
2. Review the Data, Inventory, and Analysis section
3. Read policy context and background
4. Note: For visual maps, refer to original PDFs if available

### Step 5: Cross-Reference with Land Development Code

The Comprehensive Plan sets the policy framework; the Land Development Code (LDC) implements it through specific regulations.

**After reviewing comp plan policies, check:**
- Kissimmee City Code (KissimmeeFLCodeofOrdinancesEXPORT20250822.xlsx)
- Especially Part III: Land Development Code
- Verify that application complies with BOTH comp plan policies AND LDC regulations

## Understanding Policy Language

### Mandatory vs. Permissive Language

**"Shall"** = Mandatory requirement
- Example: "The City shall maintain level of service standards..."
- This MUST be done; no discretion

**"Should"** = Recommended but not mandatory
- Example: "Development should incorporate green infrastructure..."
- Strong recommendation; discretion allowed

**"May"** = Permissive / Optional
- Example: "The City may offer economic incentives..."
- Completely discretionary

**"Will"** = Statement of intent
- Example: "The City will coordinate with Osceola County..."
- Commitment to action

### Key Terms

**"Compatible/Compatibility"**
- Land uses that can coexist without conflict
- Consider intensity, scale, mass, height, density, traffic, noise, lighting, etc.

**"Consistent/Consistency"**
- Alignment with comprehensive plan policies
- Developments must be consistent with ALL applicable elements

**"Concurrency"**
- Infrastructure capacity must be available concurrent with development impacts
- Applies to roads, water, sewer, stormwater, parks, police, fire

**"Level of Service (LOS)"**
- Minimum acceptable performance standard for public facilities
- See CIE for specific LOS standards by facility type

## Quick Reference: Common PAB Questions

### "Is this development consistent with the comprehensive plan?"

**Check:**
1. FLUE - land use designation compatibility (Goal 1.2)
2. FLUE - community character objectives (Goal 1.1)
3. TE - transportation/land use linkage (Goal 2.2)
4. CIE - concurrency compliance (Goal 8.1)
5. Element-specific policies based on project characteristics

### "Does this meet density/intensity requirements?"

**Check:**
- FLUE Objective 1.2.X for the applicable land use category
- Each land use designation has specified density (dwelling units/acre) or intensity (FAR)

### "Are we protecting environmental resources?"

**Check:**
- CONS Goal 5.1 (especially Objectives 5.1.3, 5.1.4, 5.1.7, 5.1.8)
- FLUE Objective 1.1.5
- PFE Chapters 4C and 4D

### "Is there adequate infrastructure capacity?"

**Check:**
- PFE Goal 4.1 (water), Goal 4.2 (wastewater), Goal 4.4 (stormwater)
- CIE Goal 8.2 and LOS standards
- Concurrency determination in staff report

### "Does this support multimodal transportation?"

**Check:**
- FLUE Objectives 1.1.8, 1.2.11 (if MMTD)
- TE Goals 2.1 and 2.2
- Street typology and access management requirements

### "Are we getting adequate affordable housing?"

**Check:**
- HE Goal 3.1 (especially Objectives 3.1.1 and 3.1.3)
- FLUE Objective 1.1.1
- Local affordable housing ordinances (in LDC)

## Tips for Effective PAB Analysis

### 1. Prepare Before Meetings
- Download agenda packet early
- Pre-read all applications
- Search GOPS document for applicable policies
- Flag key policies for discussion

### 2. During Meetings
- Keep GOPS text file searchable on laptop/tablet
- Reference specific policy numbers when speaking
- Quote exact policy language when possible
- Ask staff to address specific policies if unclear

### 3. Making Your Case
- ✅ **Do:** "This application is inconsistent with Policy 1.1.2.3, which states..."
- ✅ **Do:** "I'm concerned about compliance with the concurrency requirements in Objective 8.1.4..."
- ❌ **Don't:** "I just don't like this project"
- ❌ **Don't:** Make decisions based on personal preferences without policy basis

### 4. When in Doubt
- Ask staff to provide written consistency analysis
- Request additional information showing compliance
- Table the application if insufficient information provided
- Cite specific policies requiring clarification

### 5. Document Your Reasoning
- State which policies support your decision
- Explain how the application does/doesn't meet policies
- Create a record for potential appeals
- Help future PAB members understand precedents
